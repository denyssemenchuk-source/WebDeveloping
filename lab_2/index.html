4.2 Cascade (Каскад) & 4.3 Specificity (Специфічність)

Аналіз правил каскадування стилів за порядком оголошення та калькуляція специфічності (a, b, c).

4.2. Порядок каскаду (Source Order)

Cascade Resolution

Елемент має два класи .color-rule-a (Blue) та .color-rule-b (Red) з однаковою специфічністю (0, 1, 0).

Текст каскадного тесту: .color-rule-a + .color-rule-b
/* Пояснення: Порядок класів у атрибуті class="b a" НЕ впливає на пріоритет! Перемагає правило, оголошене ПІЗНІШЕ в CSS-файлі (Source Order Rule). */ .color-rule-a { color: #2563eb; } /* Оголошено 1-м */ .color-rule-b { color: #dc2626; } /* Оголошено 2-м -> ПЕРЕМАГАЄ */

4.4 Inheritance (Успадкування) & 4.5 CSS Variables Scope

Аналіз роботи спадкування властивостей (шрифти, колір) та локальної області видимості custom properties.

4.4. Успадкування властивостей

Parent Container

Контейнер має властивості: font-family: 'Courier New' та color: #9333ea (фіолетовий).

1. Елемент <p>: Природно успадкував колір та шрифт від батька.

2. Елемент <a> (Default): Браузерний стиль (User Agent) блокує колір.
3. Елемент <a class="link-inherited">: color: inherit;

/* Рішення для нормалізації спадкування: */ button, input, select, textarea { font-family: inherit; font-size: inherit; } a.nav-link { color: inherit; }

4.5. Область видимості CSS Variables

Scoping & Tokens

Змінні, оголошені в :root, є глобальними. Їх можна перевизначати локально в окремих селекторах.

Глобальний Scope (:root)

Використовує значення за замовчуванням: var(--color-bg-surface).

Локальний Scope (.card--dark)

Перевизначено: --card-bg: #1e1b4b; --card-text: #f5f3ff;

.card { background: var(--card-bg, var(--color-bg-surface)); color: var(--card-text, var(--color-text-primary)); } .card--dark { --card-bg: #1e1b4b; /* Локальний оверрайд */ --card-text: #f5f3ff; }

4.6. Повторне використання стилів (DRY)

Компонентний підхід замість унікальних стилів для кожного окремого елемента.

❌ Погано: Дублювання (Non-DRY)

/* 50 рядків дубльованого коду для кожної кнопки */ #submit-btn { padding: 10px 20px; border-radius: 8px; background: blue; color: white; cursor: pointer; } #cancel-btn { padding: 10px 20px; border-radius: 8px; background: gray; color: white; cursor: pointer; }

✓ Добре: Компонентний підхід (DRY)

/* Базовий клас .btn + модифікатори .btn--* */ .btn { padding: 0.625rem 1.25rem; border-radius: var(--radius-md); font-family: inherit; cursor: pointer; } .btn--primary { background: var(--color-primary); } .btn--secondary { background: var(--color-bg-subtle); }
